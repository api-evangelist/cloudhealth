# CloudHealth

> VMware Tanzu CloudHealth (Broadcom) is a multi-cloud FinOps platform — cost reporting, asset inventory, perspectives (groupings), policies, FlexReports, savings-plan recommendations and partner/MSP billing across AWS, Azure, GCP and OCI. It exposes a REST API (https://chapi.cloudhealthtech.com), a GraphQL API (https://apps.cloudhealthtech.com/graphql) and an OAuth-protected hosted MCP server (https://apps.cloudhealthtech.com/mcp).

Generated by API Evangelist on 2026-09-16 from apis.yml and the artifacts in this repository; CloudHealth publishes no llms.txt of its own.

REST calls send `Authorization: Bearer <api_key>` (or `?api_key=`). GraphQL calls first exchange the API key with the `loginAPI` mutation for a 15-minute access token. Published limits: REST 30 requests/minute and GraphQL 60 requests/minute per client; 429 on exhaustion.
